# altyapi dal notu

- **Çok oyunculu hazırlık (1. adım, ağsız):** oyun katmanı çok araçlı. `fizik/arac-ornegi.ts` (AracOrnegi: sim + rng + bağlam + girdi kaydı), yerel araç `oyun/surus.ts → yerel` (`sim = yerel.sim`; kamera/ses/HUD ona bakar, davranış aynı). Dünya sorgusu araç başına (`dunyaSorgusuYap`; yerel araç `dunya.cur`'u günceller, diğerleri kendi bölgesini).
- **Uzak araç:** `fizik/anlik.ts` (AracAnlik: 28 düz sayı alanı, `ANLIK_ALANLARI` sırası = ağ biçimi; UzakArac tamponu, 0,12 sn gecikmeli ara değer, en çok 0,3 sn ileri tahmin). `oyun/uzak.ts` (`uzakAracEkle`, `uzakAnlikEkle`: ağ katmanı buraya bağlanacak), çizim `cizim/uzak-arac-modeli.ts` (malzemeler kopyalanır; hayalet yarı saydam).
- **Girdi kaydı:** `fizik/girdi-kaydi.ts`, adım başına 8 bayt, fiziğe nicemlenmiş girdi gider (oynatma birebir). `sifirla` artık rng'yi ve DR/D'yi tamamen sıfırlar. Test `tests/birim/cok-arac.test.ts`.
- **Geliştirici hayaleti:** deneme sürümünde Ayarlar → Mekanikler → "Hayalet araç": yerel aracın görüntüleri 15 Hz, 2 sn gecikmeyle uzak araca (ağ benzetimi). Testte `LT.hayalet.zorla`. e2e bölümü `cok-arac` (ekran görüntüsü `tests/cikti/cok-arac.png`).
- Ölçüm öncesi/sonrası birebir aynı (0-100, tur süreleri); adım maliyeti 0,554 → 0,566 ms (gürültü).
- **Açık işler:** ağ katmanı ve sunucu (ayrı iş); uzak araç sesi (rpm/gaz anlıkta var); araç-araç çarpışması yok; kurulum (önayar) kayıt ortasında değişirse kayıt oynatılamaz (işaretlenmiyor); açık dünyada "yeniden doğ" kaydı `kesik` yapar. Birden çok fizikli araç aynı anda koşarsa `ortam`/`yaris.EV` hâlâ ortak (oturum düzeyinde, sorun değil).
- **Ekran düzeni (yön/ölçü):** manifest `orientation: "landscape"`. iOS ana ekranda yön kilitlenemediği için dikey tutuluşta içerik 90° döndürülmüş yatay olarak durur (ROT mantığı korundu).
- **Dikey açılış → yatay boşluk (kök neden; dalda, 0.3.13 regresyonu bitince denemeye):** ölçü `innerWidth`/`visualViewport`'tan alınıp #app'e px yazılıyordu; iOS standalone'da bunlar dönmeden sonra eski (dikey) değerde kalıyor, yeni resize gelmiyor. Artık ölçü CSS ile ekranı kaplayan ölçüm kutusundan (`probe`, fixed inset:0, `gorunurOlcu`), değişince ResizeObserver (`olcuIzle`) + olaylarda 1,5 sn tekrar; dönme yokken #app boyutu tamamen CSS (inline px yok); kalan kaydırma sıfırlanır. Zamanlayıcıyla tekrar ölçmek tek başına yetmemişti (0.3.11).
- Test: e2e `ekran-yon` (P1); iOS benzetimi: pencere ölçüleri dondurulup çevrilir, #app + tuval + WebGL çizim boyutu tam kaplamalı (eski kod bu testte kalıyor). Görüntü: `--goruntu` → `tests/cikti/ekran-yon-dikeyden-yataya.png`. Cihazda doğrulama kullanıcıda.
- **Ekran uyum denetimi (sanal cihazlar, 0.4.x):** `npm run cihaz` (docs/CIHAZ.md). 25 cihaz (`tests/cihazlar.mjs`: iPhone 6, Samsung 7, Xiaomi 3, Huawei 2, Pixel 3, tablet 3, tarayıcı sekmesi varyantları), 17 ekran (`tests/yardimci/cihaz-ekranlari.mjs`, sahibi menu/garaj/hud), ölçüm `cihaz-olcum.mjs`. Güvenli alan CDP `setSafeAreaInsetsOverride` ile; iPhone çentiği hata, Android delik ölçüsü yaklaşık olduğu için uyarı. Denetimin kendisi bozuk sayfalarla doğrulanır (`cihaz-dogrulama`, altyapi/cihaz-denetim).
- Senaryolar `menu|garaj|hud/cihaz-uyum` (P2): (eski kapsam, kullanıcı isteğiyle küçüldü: aşağıya bak). `npm run test:e2e` cihaz bölümlerini koşmaz (pahalı).
- Gerçek bulgular (düzeltme menu/garaj/hud'un): garaj "Motoru dinle" 150×33 (<40); pist ayrıntısı ekranı 11 cihazda dikey kayıyor; HUD düzenleyici paneli küçük yükseklikte 6 px taşıyor (10 cihaz); iPhone SE'de ana menü panelleri üst üste biniyor; Android'de vitrin ▶ ve yarış türü ▶ tuşu delik kamera bandında (uyarı).
- Karar: yan kartları eğik kapak akışı `haric` ile (yalnız `.tk:not(.on)`); başka `haric` ekleme, hatayı gizleme.
- **Cihaz kapsamı küçüldü (kullanıcı isteği, maliyet; geliştirme aşamasında kritik değil):** regresyon = iPhone 13 bütün ekranlar + 11 temsilci cihaz × 4 ekran (menu-ana, pist-ayrinti, garaj-yaris, yaris-asfalt): 61 hücre, ölçülen 143 sn (eski 425 hücre ≈ 8-12 dk). `alan` = dalın kendi ekranları, iPhone SE/13/Galaxy S8: menu için cihaz payı 42 sn (eski 7×17 ≈ 3 dk). Tam liste elle `npm run cihaz -- --hepsi`. Denetim kuralları aynı, `cihaz-dogrulama` geçiyor.
