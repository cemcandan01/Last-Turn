- Eşikler ölçümle: `npm run olcum -- pistler` (~11 dk, `TUR=gp` ile tek tür), `-- drift-puan` (~2 dk). Çarpanlar ölçüm dosyalarında (`YILDIZ_PAY`, `DRIFT_PAY`); eşik yukarı yuvarlanır.
