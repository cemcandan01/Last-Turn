# fizik dal notu

- Debriyaj vuruşu (kullanıcı isteği: başlangıç araçlarıyla drift pistinde patinaj atamıyordu): `gi.dbr`, `model.ts` (`serbestDevir`, `vurusT`, `VOLAN`, `VURUS_T`, `VURUS_SURE`); tuş `#dbr` (`kontroller.ts`, `stil.css` `.tsut`), Göstergeler → Debriyaj Açık/Kapalı. Basılıyken motor kendiliğinden devirlenir (dokunmatikte başparmak gazdan kalksa da vuruş olsun). Ölçüm `npm run olcum -- debriyaj`: Kızıl Ok gerçekçi, Drift Okulu 58 km/s: debriyajsız 23° drift yok, debriyajla 56° drift modu, spin yok.
- "Drift pistine özel kod" arandı: yok. Bütün asfalt `SURF[1]`; pist türüne bağlı tek şey `uz` (gp aracı gp pistinde +%12 tutuş; drift pistinde etkisiz). Kızıl Ok'un driftte zorlanması kendi önayarından (yarış lastiği, diff 0,45, drift eşiği 0,55).
- Drift pilotuna debriyaj denendi, bırakıldı: Kızıl Ok gerçekçide pilot girişi çok hızlı yapıyor (≤%5 kombo; pilot drift araçlarına göre ayarlı).
- Modifiye + performans puanı (büyük işin 1. adımı; sözleşme `docs/ALANLAR.md` fizik): `src/arac/parcalar.ts` (PARCALAR 43 parça / 12 kategori, PAKETLER 5 + öneri, `aracKur`, `parcaliKurulum`, `paketTak`), `src/arac/performans.ts` (puan 100-999, SINIFLAR, `performansPuani(arac, parcalar, tur?)`, `sinirdaEnIyi`). Oyuna bağlı değil: garaj/altyapı `parcaliKurulum`u `applyPreset` yerine çağıracak. Stok = aynı nesne, fizik birebir.
- Fizik kancaları (stokta etkisiz): `uzT` (tür uyumu), `dmax` (açı kiti 57°), `dk` (diferansiyel kenetleme; stok 220 neredeyse kilitli, diff ayarı bu yüzden hissedilmiyordu), `fq` (süspansiyon frekansı mutlak). Yeni lastikler TIRES 4-6 (Sokak, Spor, Drag); serbest sürüş lastik listesinde de görünür.
- Puan: nokta kütle modeli; türe göre 4 referans: asfalt (sentetik pist), rallikros ve ralli (pist 1-4 tariflerinin sabit kopyası, türün tam paket uyumuyla), drag 400 m. Genel = asfalt/rx/rl büyüğü. KALIBRE pilot turlarına uyduruldu (`-- kalibre`): gp4 puan↔süre %3,0, gp2 %5,3, rl2 %5,0 (drift ayarlı araçlar hariç: pilot drift ayarında yavaş).
- Denenip bırakılan: tek puan (en iyi zemin; asfalt araçları toprakta fazla puanlandı), tek toprak puanı (rx ile rl farklı), uz'suz toprak puanı (güçlü 4×4'ü düşük gösterdi).
- Paket ≥2/3 takılıysa önayar da o türün (drift tabanlı araca asfalt paketi = drift ayarı kalmasın). Toprak paketine öneri dört çeker, drifte arkadan itiş.
- Uyum (`-- sinif`, aynı puan): asfalt gp4 paketli −3,5…+5,5% (çoğu ≤2,3); drag 3,7-10% (Kızıl Ok/Gri Atmaca 5,2); rx2 Kızıl Ok 0,9, T.Ejder 4,1, diğerleri ~10; rl2 Kor RX −1,5, G.Atmaca 5,4, K.Ok 6,7, diğerleri 8-24; drift puanı ±17. Stokta tür aracı her türde belirgin önde (4-140%).
- Açık: toprakta ve driftte ≤%2-3 hedefi tutmuyor (pilot oynak, drift puanı puanla zayıf ilişkili); ekonomi: Kızıl Ok ücretsiz ama B 579, Panda D 233; zayıf araçlar (Panda, Mavi Yıldız) drag/toprak sınırına çıkamıyor.
